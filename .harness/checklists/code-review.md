# Code Review Checklist（CR 固有检查清单）

CR 必须检查本清单中的适用项，并在 `code-review.md` 的 Checklist Results 表中逐项记录结果。清单定义检查规则；报告记录本次事实、证据和关联发现。

| 检查项ID | 名称 | 严重度 | 检查规则 | 失败时结论 | 适用范围 |
| --- | --- | --- | --- | --- | --- |
| CHK-CR-001 | 编译构建阻塞检查 | P0 | 发现会导致编译、类型检查、构建、服务启动或关键冒烟失败的问题时不得 PASS | REJECT | 所有代码变更 |
| CHK-CR-002 | 需求覆盖检查 | P0 | 实现不得遗漏 requirements.md 中的 SHALL 或 GWT 验收点 | REJECT | 所有功能变更 |
| CHK-CR-003 | 方案一致性检查 | P0 | 实现不得违背 design.md 中的架构决策、边界、验证契约和非目标 | REJECT | 所有标准或重构变更 |
| CHK-CR-004 | 范围外修改检查 | P1 | diff 中不得包含与当前 change-id 无关且未在 design/tasks 中授权的修改 | REJECT | 所有变更 |
| CHK-CR-005 | 测试匹配检查 | P1 | 新增或变更行为必须有对应测试、验证或明确可接受的 N/A 理由 | REJECT | 行为变更 |
| CHK-CR-006 | 证据与产物契约检查 | P0 | dev-log.md 必须符合当前 schema、含必需章节和唯一 PASS 结论，且编译、构建、启动、测试和机器复核证据完整、可信、可复现 | REJECT | 所有 apply 变更 |
| CHK-CR-007 | 安全与数据风险检查 | P0 | 鉴权、授权、数据写入、迁移、密钥、日志和外部连接不得引入明显安全或数据完整性风险 | REJECT | 涉及安全、数据或外部连接的变更 |
| CHK-CR-008 | 角色边界检查 | P0 | CR 不得修改代码、测试、配置、依赖、业务资源或上游规格产物 | REJECT | CR 阶段 |
